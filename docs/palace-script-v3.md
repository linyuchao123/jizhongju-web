# 颐和谜境｜样式雷手札 V3 分镜执行稿

依据团队提供的《颐和园5.pdf》与《颐和园5 修改版.pdf》改编。定位：悬疑探索与反转，真实园林调查，温暖归档。人物、失踪传说、手札及信物为虚构；不将情节冒充历史。

## 核心改编

把固定数字密码改为观察、比对与证词判断。悬念由“匠人去了哪里”逐步转向“这份手札是否可信”。阿衡会承认自己的推断尚未被证明。玩家最终选择保存未知、继续调查或明确以虚构故事传播，而非凭游戏胜负宣判历史。

每幕三段对话后进入独立互动，配专属插画。分支在玉澜堂与仁寿殿展开；六件信物作为观看与思考的纪念。实地照片单独记录，剧情预览不声称到访。

路线：北如意门 → 画中游 → 长廊 → 玉澜堂 / 仁寿殿 → 文昌阁 → 十七孔桥。此为剧情点位顺序，未经实地通行校核，不是导航路线。

## 序｜半本手札

地点：北如意门；画面：gate.webp；气氛：晨光 · 入局。

**旁白：** 你刚走近园门，手机里多了一份未署名的档案。封面像被翻过无数次，唯独落款处，干净得反常。

**阿衡：** 有人说，写下它的匠人在重修后失踪了。可档案里，连他的姓名都找不到。

**阿衡：** 我不想再讲一个未经核实的失踪故事。你愿意和我走一遍，看看它到底留下了什么吗？

**互动目标：** 选择你的调查身份，接下这份来历不明的委托。

**玩家问题：** 这一程，你想用什么方式寻找答案？


**入藏：** 无名手札。你接住了半本手札。阿衡在目录旁，添上了你的身份。

**提示阶梯：** 没有标准身份，选你最感兴趣的一种。 → 身份只改变提示的角度，不会限制路线。 → 三种身份都可以完整体验故事。

## 壹｜画外之景

地点：画中游；画面：huazhongyou.webp；气氛：山色 · 察景。

**旁白：** 手札上有一句被反复描深的话：“吾避于山腰，不在画中，在画外。”纸页边，画着半截窗框。

**阿衡：** 先别急着数檐角。看看眼前这一层柱檐、林木，再把目光送到湖面。

**阿衡：** 如果换一个站位，画面就变了——会不会真正的线索，是“怎么看”，而不是“数多少”？

**互动目标：** 寻找“近景、中景、远景”三层线索，留意视角怎样改变风景。

**玩家问题：** 哪一组记录，最能解释你看到的景深？

- 观察 近景 · 栏檐：眼前的建筑边缘，为远方的景色提供了观看边框。
- 观察 中景 · 林木：树冠与屋面把视线层层引向湖面。
- 观察 远景 · 湖山：远方湖山进入同一画面，这是你的现场视角，不等于已经证明某人的设计动机。
- 柱檐—林木—湖山：把三个层次一起记录（可采纳）；反馈：你留下的不是一个数字，而是一个可以被重新观察的视角。
- 只记下一个檐角数字：先把其他细节忽略；反馈：数字可以是观察的一部分，却还没有回答景色如何被组织。再看看前后层次。
- 认定这里藏着逃跑暗号：直接用传说解释现场；反馈：这个推断很有戏剧性，但眼前的景物还支持不了“逃跑暗号”。

**入藏：** 借景之镜。你获得了“借景之镜”。镜面映出的，是你开始认真观看的那一刻。

**提示阶梯：** 先找离你最近的一根柱或一道檐。 → 再找中间的树冠与远方的湖面。 → 选择同时记录三个层次的观察。

## 贰｜一廊千面

地点：长廊；画面：corridor.webp；气氛：廊影 · 留痕。

**旁白：** 廊下的光一格一格落在地上。手札背面，忽然显出一行较新的字迹：“你看见的，是风景，还是别人替你选好的答案？”

**阿衡：** 这一页的笔迹和前面不同。也许我们读到的，早就不止一个人的故事。

**阿衡：** 这一次，别替他作答。挑一眼你愿意记住的风景，给它起个名字。

**互动目标：** 给这一眼风景起个名字；实地游玩时，也可以拍下自己的廊间画面。

**玩家问题：** 为你的廊间画面命名


**入藏：** 廊间画笺。“廊间画笺”已收入行囊。这一次，手札上留下的是你的字。

**提示阶梯：** 可以写下光线、颜色或一种心情。 → 不用寻找官方“标准取景角度”。 → 选择任一建议标题，或输入自己的名字。

## 叁｜红墙两面

地点：玉澜堂 / 仁寿殿；画面：yulan.webp；气氛：宫墙 · 辨言。

**旁白：** 一页断札，指向两处宫殿。馆藏摘要里，一个声音断言：“只要看懂这些构件，就能知道匠人当年的秘密行动。”

**阿衡：** 这句话太确定了。一个构件，真的能替一个人的一生作证吗？

**阿衡：** 去玉澜堂，或去仁寿殿。我们不赶着判案，先听完两边的说法。

**互动目标：** 选择一条调查支线，辨别观察与推断之间的距离。

**玩家问题：** 你想先走近哪一面宫墙？

- 支线 玉澜堂：“这些旧构件，足以证明手札主人曾秘密帮助过光绪。”
- 支线 仁寿殿：“只凭殿前器物的位置，就能还原宫廷里的全部权力关系。”
- 记录所见，暂缓推断：构件或陈设不能单独证明人物行动（可采纳）；反馈：你为证词盖上一枚留白之印：把能确定的写清，把未知的留下。
- 故事动人，直接采信：先把秘密行动写进结论；反馈：动人的叙述还需要来源。请把眼前观察和人物行为的推断分开。
- 一概视为毫无价值：连现场观察也一起舍弃；反馈：证据不充分，不等于观察没有价值。值得保留的是所见，待核实的是推断。

**入藏：** 留白之印。你获得了“留白之印”。有时候，诚实的空白，比笃定的答案更接近真相。

**提示阶梯：** 先问：这句话描述的是所见，还是人物动机？ → 器物可见，不等于秘密行动已经被证实。 → 选择保留观察、暂缓人物行为推断。

## 肆｜被改写的数字

地点：文昌阁附近；画面：wenchang.webp；气氛：湖岸 · 校勘。

**旁白：** 东堤风起，远处佛香阁的轮廓浮在树梢上。手札写着：“第四层见真章。”

**阿衡：** 等等。我们一路都在追数字，可是“层”和“檐”，真是一回事吗？

**阿衡：** 我找到一条可核查的官方说明。先把两段话放在一起，再决定哪一句该改。

**互动目标：** 对照官方建筑介绍，找出手札中混用的概念。

**玩家问题：** “第四层”这句话，应该怎样校勘？

- 分清楼层与重檐：三层、四重檐，不是四层楼（可采纳）；反馈：抄录者把“三层四重檐”简化成了“第四层”。一处错误，让整套数字密码开始松动。
- 仍把四作为唯一密码：不必核对题目是否成立；反馈：一个数字可能来自错误抄录。先检查概念，才能判断“密码”是否真的存在。
- 宣布已发现秘密防线：用建筑轮廓推出军事结论；反馈：目前资料不足以支持这个结论。我们可以保留故事想象，却不能把它写成史实。

**入藏：** 重檐校样。你获得了“重檐校样”。真正破解的，是一道写错的题。

**提示阶梯：** 官方说明里同时出现了“三”和“四”。 → 一个描述楼层，一个描述檐。 → 不是四层楼，而是三层四重檐。

## 终｜失踪的，是谁

地点：十七孔桥东岸；画面：bridge.webp；气氛：夕照 · 归卷。

**旁白：** 桥影落进湖里。你把手札翻到最后，那里没有逃亡路线，也没有一个等你揭晓的真名。

**阿衡：** 我一直以为，只要走到终点，就能替那个“失踪的人”找回名字。

**阿衡：** 可我们找到的，是不同年代的笔迹、被改写的数字，和一个还没有足够证据的传说。也许，真正差点丢失的，是认真看待这座园林的方式。

**互动目标：** 把沿途证据归位，为手札选择一种诚实的结尾。

**玩家问题：** 你愿意把这份手札，留给未来的人怎样阅读？

- 为未知保留一页空白：归为来源未明，保留调查与来源
- 把好奇心留给下一程：列出待解问题，继续寻找可信资料
- 把这段冒险写成故事：明确标注虚构，传递你看到的园林

**入藏：** 桥影留笺。“桥影留笺”已收好。你走过的这一路，终于有了自己的署名。

**提示阶梯：** 这些证据还不能证明“失踪匠人”确有其人。 → 你的选择决定讲述方式，不会改写真实历史。 → 三个结局都保留事实与想象的边界。

## 三种终章

- 审慎守护者：保留来源与调查，未知处暂不定案。
- 继续追寻者：留一份待解清单，继续找可信材料。
- 故事传递者：标清虚构，分享自己的观看。

## 演示与实现范围

NPC 为编写的分支回应，尚未接入实时模型。进度写入 localStorage，照片压缩后存 IndexedDB；无云同步。纪念图可导出 PNG。角色身份用于叙事与提示角度，三种身份均不锁定路线。场景插画为艺术化演绎，不能作测绘或文物复原依据。
